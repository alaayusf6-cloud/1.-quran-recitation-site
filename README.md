# منصة التلاوة الصحيحة — نسخة GitHub Pages + Google Drive

موقع عربي RTL جاهز يعرض سور القرآن الكريم، ويتيح للطالبة مشاهدة فيديو السورة ثم رفع ملف صوتي أو فيديو. الملف يُرسل إلى Google Apps Script ثم يُحفظ داخل Google Drive في مجلد مستقل لكل سورة.

## الملفات

- `index.html` — الصفحة الرئيسية.
- `style.css` — التصميم.
- `script.js` — عرض السور، الفيديو، ورفع الملفات.
- `surahs.js` — **هنا تضع روابط فيديوهات السور الـ114**.
- `config.js` — اسم المدرسة ورابط Google Apps Script.
- `Code.gs` — كود Google Apps Script الذي يحفظ الملفات في Drive.

## 1) إضافة روابط فيديوهات القرآن

افتح `surahs.js`. أمام كل سورة ستجد:

```js
{ number: 1, name: "الفاتحة", videoUrl: "" },
```

ضع الرابط هكذا:

```js
{ number: 1, name: "الفاتحة", videoUrl: "https://www.youtube.com/watch?v=XXXXXXXXXXX" },
```

كرر ذلك لكل سورة. الموقع يدعم روابط YouTube العادية، youtu.be، shorts، وروابط embed. ويمكن أيضًا استخدام رابط مباشر لملف فيديو.

## 2) تجهيز Google Drive

1. أنشئ مجلدًا في Google Drive مثل: `تسليمات تلاوة القرآن`.
2. افتح المجلد وانسخ الـ Folder ID من الرابط.
3. افتح `Code.gs` وضع الـ ID هنا:

```js
const ROOT_FOLDER_ID = 'PUT_YOUR_GOOGLE_DRIVE_FOLDER_ID_HERE';
```

الكود سينشئ تلقائيًا مجلدات مثل:

```text
تسليمات تلاوة القرآن/
├── سورة الفاتحة/
├── سورة البقرة/
├── سورة آل عمران/
└── ...
```

وسيكون اسم الملف مثل:

```text
سارة-أحمد_السابع-أ_سورة-الملك_2026-10-06_15-30.mp4
```

## 3) نشر Google Apps Script

1. افتح Google Apps Script وأنشئ مشروعًا جديدًا.
2. الصق محتوى `Code.gs`.
3. من **Project Settings** اضبط المنطقة الزمنية المناسبة إن رغبت.
4. اضغط **Deploy > New deployment**.
5. اختر **Web app**.
6. اجعل **Execute as: Me**.
7. اختر مستوى الوصول المناسب. إذا أردت أن ترفع الطالبات بدون تسجيل Google فسيحتاج الـ Web App إلى قبول الوصول العام/Anyone حسب الخيارات المتاحة في حساب المدرسة.
8. اضغط Deploy، ثم انسخ رابط Web App المنتهي بـ `/exec`.

## 4) وضع رابط Apps Script في الموقع

افتح `config.js` وضع الرابط:

```js
appsScriptUrl: "https://script.google.com/macros/s/XXXXXXXXXXXX/exec",
```

ويمكنك أيضًا تغيير:

```js
schoolName: "اسم المدرسة",
siteTitle: "منصة التلاوة الصحيحة",
```

## 5) رفع الموقع إلى GitHub Pages

1. أنشئ Repository جديدًا في GitHub.
2. ارفع ملفات الموقع: `index.html`, `style.css`, `script.js`, `surahs.js`, `config.js`.
3. لا تحتاج رفع `Code.gs` للموقع؛ هذا الملف فقط للاحتفاظ بكود Apps Script.
4. من Settings > Pages اختر النشر من الفرع الرئيسي.

## ملاحظة مهمة عن الخصوصية

GitHub Pages موقع عام افتراضيًا، ورابط Apps Script الموجود في JavaScript يمكن رؤيته من المتصفح. هذا مناسب كـ MVP مدرسي بسيط، لكنه ليس نظام مصادقة آمنًا. إذا سيصبح الموقع عامًا على نطاق واسع أو ستُرفع تسجيلات حساسة، يفضل لاحقًا إضافة تسجيل دخول/مصادقة وخدمة Backend محمية.

## حجم الملفات

النسخة الحالية تضبط الحد على 25MB لأن الملف يُحوّل إلى Base64 ويمر عبر Apps Script. للتسجيلات الطويلة أو الفيديوهات الكبيرة، يفضل ضغط الفيديو أو تطوير آلية رفع أكثر ملاءمة لاحقًا.
